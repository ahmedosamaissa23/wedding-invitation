# Ahmed & Fadwa — Wedding Invitation

A single-page wedding invitation website.

- **Date:** September 10, 2026
- **Venue:** Bashla, Mit Ghamr, Dakahlia Governorate

## View

Open `index.html` in any web browser, or visit the published GitHub Pages link.

## Publish on GitHub Pages

1. Create a new repository on GitHub and upload `index.html` (and this `README.md`) to it.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment → Branch**, choose `main` and the `/ (root)` folder, then click **Save**.
4. Within a minute the site is live at:
   `https://<your-username>.github.io/<repository-name>/`

## Notes

- The background music and both images are embedded inside `index.html`, so the site is fully self-contained — no extra asset files are needed.
- The background music begins 5 seconds after the guest opens the doors (browsers require a user click before audio can play).
